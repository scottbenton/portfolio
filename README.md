Hey! This is my portfolio project. If you wanted to see the code, you are in the right place. If you wanted to see the website itself, please check out [scottbenton.dev](https://scottbenton.dev).

## Running this locally

1. Make sure you have node and NPM installed.
2. Clone the project locally.
3. Run `npm i` to install the dependencies
4. Run `npm run dev` to start the development server.
